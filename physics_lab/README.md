# ESP32 Physics Lab（掌上物理实验室）

从 `/mnt/documents/桌面/wuli` 的“粒子先生物理实验室”中蒸馏出的 ESP32 简化项目。

## 目标

在 Waveshare ESP32-S3-RLCD-4.2（400×300 1bpp）上做一个可交互的物理实验入口：

- 实时物理模拟
- 摇杆/按键改参数
- 公式、读数、轨迹
- 后续可接现有语音助手，用 Qwen 解释实验现象

## 不搬什么

- Next.js / React / Electron
- 56 个网页实验
- MuJoCo/WASM 3D
- 代理缓存、会员鉴权、远程 API
- 完整知识图谱和 AI 教学状态机

## 保留什么

- “看见物理”的核心：参数变化 → 实时图像 → 读数/公式
- 一个实验一个屏幕，先做深，不做多
- 苏格拉底式提问以后接语音助手，不先做系统

## 集成方式

作为现有固件的一个独立模块，而不是第二个固件：

```text
game_proto/main/
  physics_lab.cpp / physics_lab.h
  菜单第 6 项：物理实验
```

优点：

- 一块板、一个固件
- 不影响游戏、语音、VAD
- 可单独开关
- 以后需要独立固件时再拆

## 第一阶段：平抛运动

参数：

- 初速度 v0：5–30 m/s
- 高度 h：0–20 m
- 重力 g：9.8 m/s²

画面：

- 坐标轴、地面、轨迹点
- 小球实时位置
- 读数：t / x / y / vx / vy
- 公式：x=v0t，y=h-½gt²

控制：

- 摇杆左右：v0
- 摇杆上下：h
- A：发射/重置
- B：切换实验（后续）
- A+C：返回菜单

验收：

- 轨迹与公式一致
- 25fps 稳定
- 不阻塞语音/采集任务
- 返回菜单不泄漏内存
