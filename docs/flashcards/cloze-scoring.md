# 扣分明细（v0.71.2）

## 提示扣分
```text
提示扣分 -3 · 第2次 · 共6
```
事件：
```json
{"type":"score","delta":-3,"reason":"hint","detail":"第2次使用原文，本级共减6"}
```

## 时间扣分
自由时限：
```text
120 秒 + 每页 15 秒
```
超过后每 45 秒 -1，最多扣基础分 20%。
事件：
```json
{"type":"score","delta":-1,"reason":"time","detail":"用时4:12，自由时限3:30"}
```
