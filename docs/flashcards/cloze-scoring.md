# 加分、减分与结算反馈（v0.71.0）

## 使用提示
- 不弹大窗口
- 底部显示：`提示3 扣0`
- 每用一次原文：立即写 score 事件，delta=-3
- 当前级别提示用完即止

## 通过本级
弹一次结算条：
```text
L4通过 +25 -3 = +22分
```
含义：
```text
基础分 +25
提示扣分 -3
本次净分 +22
```

## 事件
```json
{"type":"score","level":4,"delta":-3,"total":42,"reveals":1}
{"type":"score","level":4,"delta":25,"total":67,"reveals":1}
```

## UI
- 用提示：底部 `提示N 扣M` 轻反馈
- 通过本级：统一结算一次
- 统计页：累计净分
