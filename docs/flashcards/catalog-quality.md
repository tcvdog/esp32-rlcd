# 教材文本质量门禁

## 原则
公开数据集不能直接等同于教材正确文本。当前 198 条已完成结构校验，但没有完成逐篇教材对照，因此不能宣称“孩子学习绝对无误”。

## 已接入的自动校验
`tools/validate_catalog.py` 发布前必须通过：

- 198 条目录计数
- 标题/作者非空
- 正文非空
- 5 级遮罩齐全
- 遮罩不能改写原文
- 遮罩只能盖汉字，不能盖标点
- 遮罩可无损还原
- 20px 字库覆盖全部正文汉字
- 替代来源计数

当前结果：

```text
entries=198 alt=12 errors=0 warnings=3
```

警告是跨学段重复标题，不是错误。

## 还需要人工完成
1. 以人教版教材扫描页/官方电子教材为唯一底稿。
2. 每篇记录册次、单元、页码、来源 URL/哈希。
3. 两人独立录入/校对，第三人抽检。
4. 逐篇确认繁简、异体、通假、标点、段落和作者。
5. 给每篇写入 `verified` 状态；未验证篇目在儿童学习模式中不开放。

## UI 建议
```text
已校对   正常学习
待校对   只读/不进入学习
非课本   保留替代标记
```

## 结论
机器校验能防止“遮罩改字、缺字、结构错位”，不能单独保证“教材文字一字不差”。最后一道门必须是教材底稿对照和人工签字。
