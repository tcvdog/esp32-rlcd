# 《出师表》镂空背诵卡（v0.66.4）

## 入口
闪卡记忆 → 05 诗词古文 → 第 1 篇《出师表》。

## 5 级镂空
- L1：约 10%
- L2：约 30%
- L3：约 37%（整词 + 不相邻硬约束）
- L4：约 38%（优先保证整词和不连遮，未强行凑 70%）
- L5：全遮蔽默写（仅保留标点、分段）

生成时用 jieba 分词，只遮完整词；被遮词之间至少留一个未遮词，单次不超过 4 字。保持每个字符的位置、标点、换行；中文遮蔽为原位白圈：先画原字，再用白格+黑环覆盖，不替换字符、不改变字距。
虚词默认不遮；每句保留一个锚点（L5 除外）。

## 提示位置
`换篇 / 调级 / 翻页   镂空遮挡 K3 显示原文` 位于正文框外底部行，不占用正文。

## 操作
```text
摇杆 上/下      L1..L5
摇杆 左/右      翻页
K1 / C          上一篇
K2 / D          下一篇
K3 / A          显示原文 / 返回镂空
K4 / B          返回分类
```

## 文本

## 诚实标注
- 镂空在构建时用 jieba 分词生成，不是设备端实时分词。
- L4 实测约 66%，因每句锚点与虚词保护没有强行补到 70%。
- 后续数学/物理定理可复用同一卡型，但需要新的文本与分级数据。
