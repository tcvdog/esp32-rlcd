## 2. 建议的动作树

### 普通拳脚

| 输入 | 动作 | 定位 | 分镜 |
|---|---|---|---|
| A | Jab | 最快、可连 | 收拳 → 前手直刺 → 回收 |
| A A | Hook | 中段、可取消 | 转肩 → 横摆 → 收势 |
| A A A | High Kick | 三连终结 | 提膝 → 高扫 → 落地 |
| B | Low Kick | 下段 | 沉髋 → 低扫 → 回站 |
| ↓+B | Low Sweep | 下段击倒 | 蹲身 → 扫腿 → 起身 |
| 空中 B | Jumping Kick | 空对地 | 收腿 → 斜下踢 → 落地 |
| C | Heavy Hook | 重击 | 大转肩 → 重摆 → 硬直 |
| →+C | Rising Knee | 对空 | 下蹲 → 顶膝 → 上升 |

### 防御 / 闪避 / 反击

| 输入 | 动作 | 说明 |
|---|---|---|
| 后退（被攻击时） | Block | 现有 guard，保留 |
| ↓+←/→ + B | Roll | 8–10 帧无敌，滚到身后 |
| 双击后退 | Evade | 短距离后撤，无伤害 |
| 防御中 A | Counter | 弹开一次攻击后短窗口反击 |
| 近身 C | Grab | 抓取 → 投掷，破防 |

### 特殊技 / 大招

| 输入 | 动作 | 消耗 | 定位 |
|---|---|---|---|
| QCF + C/D | 墨旋踢 | 1 格 | 突进、中段 |
| QCB + C/D | 墨爆 | 2 格 | 近身范围、击倒 |
| 冲刺 + C | 墨影三连 | 1 格 | 三次快速斩击 |
| QCF + QCF + C/D | 墨龙破 | 3 格 | 大招、全屏演出 |

## 3. 分镜时间轴（25fps）

### Jab

```text
0–3f   收拳
3–5f   前手直刺（active）
5–9f   回收
9–12f  可取消窗口
```

### Hook

```text
0–5f   转肩蓄力
5–8f   横向摆拳（active）
8–14f  收势
14–18f 可接 High Kick
```

### High Kick

```text
0–6f   提膝
6–9f   高扫（active）
9–17f  落地/收腿
17–22f 硬直
```

### 墨旋踢

```text
0–8f   蓄墨/下蹲
8–12f  旋转突进（active，1 hit）
12–24f 收势/墨迹残留
```

### 墨龙破（大招）

```text
0–20f  全身蓄墨，背景降噪
20–26f 冲刺入画
26–36f 多段墨龙斩（3 hits）
36–50f 落地，墨迹扩散
50–60f 收势，镜头回正
```

## 4. 1bpp 表现原则

- 每个动作只保留 2–3 个关键剪影：**蓄力 / 命中 / 收势**。
- 命中帧用 1–2 帧反色/白闪，不要连续闪。
- 速度线用 1px 斜线，不用灰阶。
- 墨迹用实心块 + 飞溅点，不用渐变。
- 大招只做一次全屏反色，随后用墨迹扩散表现余波。
- 受击硬直 8–14 帧；击倒 20–30 帧；不要超过 40 帧。

## 5. 已实现（v0.60.0）

- A→A→A：Jab → Hook → High Kick
- 空中 B：Air Kick
- ↓+后+B：Roll 无敌翻滚
- 双击后：Evade 后撤无敌
- 防御 + A：Counter
- 近身 C：Grab → Throw
- QCF+C/D：墨旋踢
- ↓+后+C/D：墨爆
- 冲刺+C/D：墨影三连
- C+D：墨龙破（3 气）

## 6. 原始实施顺序

1. 先做 **Jab → Hook → High Kick** 三连击和空中踢。
2. 再做 **Roll** 和 **Counter**。
3. 再做 **Grab/Throw**。
4. 最后做 **墨旋踢 / 墨爆 / 墨龙破** 的分级。
