# 1bpp 科技感界面规范

## 结构

- 顶部黑色终端栏：`RLCD//OS`、版本、系统状态
- 二级标题：中文 + 英文微标签 + 技术刻度线
- 2×3 编号模块网格：`01–06`、中文名、英文代号
- 选中项整块反色：黑底白字，形成强焦点
- 底部遥测：SD / RTC / 电池 / 网络
- 最底部操作提示：保持单行、等宽大写

## 设计原则

1. 不用大号居中标题，改用左上角信息层级。
2. 不用双线框，改用单线框 + 四角注册标记。
3. 不用纯列表，改用可扫描的网格。
4. 中文用 16px，英文/编号用 7×13 等宽字体。
5. 科技感来自“信息密度 + 对齐 + 状态”，不是装饰。
6. 1bpp 只使用黑/白与反色，不依赖灰阶。
